# ☕ Página web estilo cafetería (HTML + CSS)

Proyecto de práctica de maquetación web: una sola página con menú de navegación, portada, tarjetas de novedades, galería de imágenes y sección de contacto, hecha solo con **HTML y CSS**.

🔗 **Ver el sitio:** https://camirodridevelop.github.io/starbucks/Starbucks3/

## Qué practiqué

- Estructura semántica en HTML (`header`, `section`, etc.).
- Maquetación con CSS: colores de marca, tarjetas, galería y pie de página.
- Diseño adaptable con `@media queries`.
- Publicación con GitHub Pages.

## Estructura

```
Starbucks3/
├── index.html    # contenido de la página
├── styles.css    # estilos
└── images/       # logo, tarjetas y galería
```

## Cómo verlo en tu computadora

1. Descargá o clonás el repositorio.
2. Abrí `Starbucks3/index.html` en tu navegador.

## Nota

Es un ejercicio de aprendizaje sin fines comerciales. El nombre, el logo y las imágenes de Starbucks pertenecen a sus respectivos dueños; no tengo ninguna relación con la marca.
